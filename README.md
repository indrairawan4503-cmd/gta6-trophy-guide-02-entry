An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI — guide-first. Every trophy shows its official name, description and grade, plus a step-by-step guide written in our own words that cites its sources (Output Lag, Keengamer, Exophase, Push Square, PSNProfiles). The checklist saves progress in the browser, exports and imports it, filters by story / missable / collectibles / activities, and hides story-trophy spoilers until a trophy is earned. A chapter-ordered roadmap leads to the platinum (Vice Got a Price!), flagging the one missable trophy — Positive Mental Attitude, whose Chapter 1 balcony meditation disappears after Chapter 1 — and the time-sensitive Race Against Yago in Chapter 3. No online trophies, no difficulty trophies, no mission replay: about 200 hours to the platinum. Works fully offline — no network requests, no Rockstar artwork.

## Run it

Serve `app/` with any static server and open `app/index.html`, for example:

```sh
node serve.ts
# then open http://localhost:8080
```

Tick trophies to mark them earned (saved in localStorage), use Export progress to download a JSON backup, and Import progress to restore it.
